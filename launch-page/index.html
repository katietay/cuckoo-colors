Cuckoo Colors

Generate printable color coordinate activities that balance creativity, logic and accessibility.

Launch the app

Editing the color list is limited to the administrator, so visitors can use every feature except changing the saved colors.

What it does

  • Choose up to 1000 rows, 702 columns and the number of colors.
  • Paint cells with a mouse, touch or keyboard (arrow keys to move, Enter or Space to paint).
  • Change a color mid-activity and every painted cell updates with it.
  • Print a clean, grayscale-friendly worksheet.
  • Colors are stored in a database and managed on their own page.

How it is built

Angular 20 front end with an API backed by a SQL database (Express and SQLite for development, PHP and MySQL in production). Server-side validation, rate limiting, a strict Content Security Policy and automated tests (API and front end) are part of the project. WCAG 2.1 AA contrast and keyboard support were design requirements from the start.
