Make a printable color-coordinate activity sheet for vision therapy. Choose how many rows, columns and colors you want, then press Generate. Paint a pattern on the grid in Table 2, and Table 1 builds a coordinate list for each color (for example "Red: A1, B3"). Print the sheet so a person can recreate the pattern from the list. Every color is shown with its name, not only its swatch.
